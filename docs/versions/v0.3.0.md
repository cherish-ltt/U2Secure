# v0.3.0 — 预编译分发 & 多平台构建

> 发布时间：2026-09-05

本版本聚焦**分发体验**：新增 npm / bun / cargo-binstall 三种预编译安装方式，官方提供 5 个平台的预编译二进制，无需本地 Rust 环境即可完成安装。

---

## 🆕 新功能

### 多平台预编译二进制（Binary Build）

GitHub Actions 在 `v*` 标签推送（或手动触发）时自动构建并上传 GitHub Release：

| 平台 | 目标（target） | 构建方式 |
|------|---------------|---------|
| Linux x86_64 | `x86_64-unknown-linux-gnu` | 原生编译 |
| Linux ARM64 | `aarch64-unknown-linux-gnu` | 交叉编译（gcc-aarch64-linux-gnu） |
| macOS Apple Silicon | `aarch64-apple-darwin` | 原生编译 |
| macOS Intel | `x86_64-apple-darwin` | 交叉编译 |
| Windows x64 | `x86_64-pc-windows-msvc` | 原生编译 |

- 产物统一命名 `u2secure-<target>[.exe]`
- Release 正文自动读取 `docs/versions/<tag>.md`（即本文件），缺失时回退为自动生成的更新日志
- 支持手动 `workflow_dispatch` 指定 tag 构建，并可标记 pre-release

### npm / bun 安装（推荐）

新增 npm 包 `@ghyper9023/u2secure`：

```bash
npm install -g @ghyper9023/u2secure
# 或
bun install -g @ghyper9023/u2secure
```

- postinstall 脚本根据当前平台自动从 GitHub Releases 下载对应二进制（Linux x86_64/ARM64、macOS x86_64/ARM64、Windows x64）
- 轻量 wrapper 转发命令行参数与退出码，行为与原生二进制一致
- 发布走 npm Trusted Publishing（OIDC + provenance），无需静态 token

### cargo-binstall 支持

`Cargo.toml` 新增 `[package.metadata.binstall]` 元数据，资产命名与 Binary Build 产物对齐：

```bash
cargo binstall u2secure
```
